### Sonare Music Club Website

An unofficial, fan-made website built for our school's music club, Sonare. I wanted to create a central place to showcase what our club is about and share our activities with other students. 

### Features

* Information and updates about the Sonare Music Club.
* A direct link to our official Facebook page so students can stay connected.
* Built entirely with code and permanently hosted on GitHub Pages.
